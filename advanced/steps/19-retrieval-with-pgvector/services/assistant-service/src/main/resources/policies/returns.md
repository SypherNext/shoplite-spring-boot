# Returns and refunds

You can return any item within 30 days of delivery, unused and in its original packaging.
Start a return from your order page; ShopLite emails a prepaid return label within one working day.
Refunds go back to the original payment method within 5 working days after the item arrives at the warehouse.
Items marked as clearance cannot be returned, but they are still covered by the warranty.
Return shipping is free for customers in the EU. Outside the EU, return shipping costs 8 EUR, taken from the refund.
